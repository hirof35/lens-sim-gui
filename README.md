# 2D Optical Lens Simulator

Node.js (Vite) と HTML5 Canvas で構築した、リアルタイムの2次元幾何光学（光線追跡）シミュレーターです。
<img width="798" height="1032" alt="スクリーンショット 2026-06-04 081909" src="https://github.com/user-attachments/assets/b1516880-9bde-4b58-8722-3f1ae5caeef7" />

## 🌟 特徴
- **リアルタイムシミュレーション:** マウスでレンズ（円）をドラッグしてリアルタイムに光線の変化を観察できます。
- **物理準拠:** スネルの法則（屈折の法則）に基づいた光線追跡を実装。
- **全反射の再現:** 入射角が臨界角を超えた際の「全反射現象」も視覚的にシミュレート。
- **純粋な幾何計算:** 外部ライブラリに頼らない、ベクトルと2次方程式を用いた交点・法線計算ロジック。
